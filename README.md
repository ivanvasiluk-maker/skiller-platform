# SKILLER Platform

SKILLER — персональная система освоения психологических навыков. Приложение помогает разобрать конкретную ситуацию, выполнить короткий навык, измерить результат и постепенно сформировать личный протокол: что, когда и в каком контексте работает для конкретного человека.

## Что уже работает

- вход через ChatGPT/Sites и отдельные данные каждого пользователя;
- серверная база D1 для ситуаций, попыток, результатов и настроек доступа;
- детерминированная проверка риска до подбора навыка;
- три навыка из разных дорожек: стабилизация, фокус, отношения и границы;
- полный цикл «ситуация → навык → практика → результат → личный протокол»;
- раздельное измерение облегчения, движения к цели и избегания;
- пользовательское управление будущим доступом психолога;
- адаптивное веб-приложение для телефона и компьютера.

SKILLER не является экстренной службой, не ставит диагнозы и не заменяет психотерапию.

Неизменное продуктовое ядро:

`ситуация → точка изменения → навык → применение → измерение → личный протокол`

## Технологии

- Vinext / React / TypeScript;
- Cloudflare Workers;
- D1 SQLite + Drizzle ORM;
- Sites authentication headers;
- Shadcn/Radix UI.

## Локальная разработка

```bash
npm ci
npm run db:generate
npm run build
```

Схема базы находится в `db/schema.ts`, миграции — в `drizzle/`, серверная продуктовая логика — в `lib/skiller-data.ts`, интерфейс — в `app/skiller-app.tsx`.

Продуктовые ограничения и информационная архитектура сохранены в `docs/PRODUCT_BIBLE.md` и `docs/INFORMATION_ARCHITECTURE.md`.

## Принцип архитектуры

LLM не принимает клинические решения. Безопасность, доступность навыков и маршрутизация остаются объяснимыми и детерминированными. AI будет подключаться позже как языковой и диалоговый слой поверх этих правил.
