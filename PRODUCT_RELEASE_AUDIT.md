# SKILLER 1.0 — аудит перед коммерческим запуском

Дата: 26.10.2026, Europe/Vilnius. Проверка исходников и локальной одноразовой D1; production не изменялся.

## Решение

| Формат запуска | Решение на дату аудита | Основание и минимальное условие изменения решения |
|---|---|---|
| Открытый бесплатный запуск / платный рекламный трафик | **NO-GO** | Исправления ещё в отдельной ветке; не подтверждены опубликованный SHA, визуальный QA, живая модель и процесс удаления данных. После принятия исправлений, проверки опубликованной версии и закрытия R06–R09 допустим ограниченный бесплатный пилот. |
| Продажи групп через SKILLER | **NO-GO** | В приложении нет проверенного пути предложение → заявка → оплата → подтверждение. Нужен один согласованный ручной путь покупки, а не разработка платёжной платформы. Внешние продажи групп этим аудитом не оценивались. |
| Платная подписка на SKILLER | **NO-GO** | Нет реализации подписки, проверки права доступа, восстановления покупки и отмены. Нельзя продавать как работающую функцию. Не добавлялась в этом цикле. |

Локальный технический PASS не равен разрешению на публичный релиз. Исправленные P0 перечислены ниже отдельно от оставшихся условий запуска. Никакие production-миграции, deploy, платежи, рассылки или реальные клиентские записи не выполнялись.

Использовались Node 24.22.1 и локальный workerd; CI использует Node 22. Все D1 проверки выполняются с тестовой конфигурацией и одноразовым локальным хранилищем. Safety hold не содержит текста клиента, сохраняется отдельно от удаляемой ситуации и снимается существующим явным safeAgain.

```bash
npm ci --ignore-scripts
npm run verify
npm run test:http
npm run test:ui
```

`--ignore-scripts` использован только для локальной установки этого аудита; стандартный CI оставлен на `npm ci`. Отдельные команды `npm run deploy:check` и проверки отказа deploy не запускают remote-операции. `test:e2e` в package.json — alias D1 integration, **не браузерный E2E**.

- **Baseline main:** полный `npm run verify` PASS до изменений.
- **Повторный verify исправленной ветки:** PASS — lint (0 errors, 2 прежних warnings в character-bible tests), typecheck, 16 Python tests, 102 Node tests, D1 smoke, integration, build и HTTP acceptance.

## 7. Минимальный план до первой продажи

1. Принять P0 в выбранную release-ветку, решить расхождение main/feature; не включать merge/deploy автоматически.
2. Закрыть данные/удаление, клиническую приёмку диалогов и визуальный QA; подтвердить ограничения расходов и безопасный ingress. Использовать синтетические данные до этого.
3. После отдельного разрешения владельца — публикация проверенного SHA и smoke. Начать с небольшой бесплатной когорты с понятными границами и поддержкой; зафиксировать активацию и завершение практики.
4. Для продажи групп — добавить только один принятый оффер и ручной путь заявки/подтверждения, проверить его без реального списания. Условие GO: тестовая заявка дошла до подтверждения, цена/условия согласованы, crisis flow не содержит продажи.
5. Подписку оставить выключенной. Новый кабинет, marketplace, полную программу ДБТ, геймификацию и расширение каталога в этот релиз не добавлять.
