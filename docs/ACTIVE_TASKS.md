## Последний раунд — N1c, 04.10.2026

Пауза практики хранится отдельно в trainer_plan_pauses (миграция 0014), result/helpfulness/attempt_id не подменяются. Связанный open loop получает paused и исключается из активных напоминаний; при возврате восстанавливается прежний active/answered. Continuity и контекст разговора не предлагают paused как текущую практику. UI показывает список с личной договорённостью и возвратом; после паузы доступна новая ситуация. Сервер запрещает изменять результат paused-плана, возобновлять при другой активной практике/разборе/follow-up/safety. Уже сохранённое выполнение не теряется. Typecheck/адресный ESLint/D1 integration/build/diff check PASS. Новый /pause-cycle проверяет отсутствие попытки до start, отсутствие выдуманного результата, сохранение после нового sessionId, скрытие из напоминаний, stale start, блокировку при другом разборе, ту же договорённость, partial без outcomes и идемпотентность. AI отключён, браузер/телефон не проверены. Пауза таймера не хранит оставшиеся секунды; production не обновлён.

- Уточнение пользователя: ранее неразборчивое название означает **DBT-ACES**, а не ACT или ACCEPTS.
