- перед Skill Engine по-прежнему требуется подтвердить или исправить актуальность черновика для текущего эпизода;
- safety и outcome policy не изменены и сохраняют приоритет;
- длинная кнопка и вторичное действие на ширине до 760 px переходят в вертикальный layout с touch-target не менее 40 px;
- integration проверяет оба независимых действия карточки: отклонение и применение памяти, а также переход применённого черновика в `chain_confirm`.

Не завершено в этом спринте: реальный визуальный smoke на 390 px и desktop — локальный `localhost` недоступен из облачного browser runner. Его необходимо выполнить на preview/deploy URL либо вручную в локальном браузере.

Следующий короткий спринт: preview/deploy визуальный smoke, затем улучшение исправления черновика по отдельным звеньям цепочки без полного повторного опроса.

## 2026-09-23 — Sprint 10: точечное исправление цепочки

- ответ «Нет, хочу поправить» больше не отправляет пользователя в неструктурированное общее уточнение;
- тренер предлагает выбрать конкретное звено: событие, мысль/смысл, эмоции/тело, импульс, действие или последствия;
- после выбора задаётся один точный вопрос только по этому звену;
- новый ответ заменяет выбранное поле в `chain_json`, остальные элементы цепочки сохраняются;
- обновлённая цепочка снова показывается целиком как рабочая гипотеза и требует подтверждения;
- механизм одинаково работает для нового подробного разбора и для цепочки, восстановленной из behavioral memory;
- integration проверяет выбор звена, изменение только мысли, повторную сборку гипотезы и сохранение исправленного варианта в память.

Следующий короткий спринт: добавить возможность последовательно исправить несколько звеньев, затем preview/deploy и визуальный smoke на desktop и реальном телефоне.

## 2026-09-23 — Sprint 11: несколько исправлений без перезапуска

- после каждого точечного изменения пользователь возвращается к целой обновлённой цепочке;

- integration проходит сценарий с последовательным изменением мысли и действия, затем проверяет сохранение обеих правок в behavioral memory.
