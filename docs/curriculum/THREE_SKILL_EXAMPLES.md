# Примеры просьбы, проверки фактов и валидации

04.10.2026. Авторские учебные примеры для существующих сокращённых карточек, для профессиональной проверки Иваном. Не заменяют полный тренинг или руководство. Источник структуры — текущий каталог приложения lib/skiller-data.ts; отдельный полный источник с точной страницей ещё не сверён.

## Что подключено

- dear-man: вечером приходят рабочие задания → наблюдаемый факт → конкретная просьба о времени → объяснение пользы планирования. Нельзя обещать согласие. Полная DEAR MAN содержит больше шагов; этот пример — короткая репетиция существующей карточки.
- check-facts: отсутствие ответа → эмоция персонажа → факт/интерпретация → несколько возможных объяснений и признание недостатка данных. Позитивная догадка не подменяет проверку; реальные признаки угрозы нельзя обесценивать. Оценка 6/10 существует только в учебной истории и не сохраняется как состояние пользователя.
- validate-first: отменённая встреча → признание или уточнение разочарования → пауза → собственная граница и выполнимый вариант. Валидация не требует соглашаться с обвинением или продолжать небезопасный контакт.

## Поведение приложения

app/skill-example.tsx выводится внутри PlanCard только для этих трёх ID. Неизвестный ID не создаёт пример. Показывает собственную договорённость отдельно, если она есть; вопросы предлагают применить пример к своей ситуации. Чтение не вызывает API и не создаёт попытку. Start, отдельное выполнение, отдельная польза, отказ и ухудшение остаются в существующем цикле. Seed, версии карточек и старые skill_json не менялись.

## Статус

Примеры есть для 6 из 8 базовых карточек: micro-start, stop, grounding-543 и эти три. Для distract-delay и urge-surfing примеров пока нет. Это показатель покрытия примерами, не полноты ДБТ. Полнота DEAR MAN, GIVE/FAST, проверки соответствия эмоций ситуации и остальных модулей остаётся отдельной задачей.

Typecheck, адресный ESLint и build проверяются в этом раунде. Браузер, телефон и production здесь не проверяются.
