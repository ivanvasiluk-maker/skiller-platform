# Шаблон клиентского упражнения v0.1

Это спецификация наполнения, не новая таблица production. Не превращать поля ниже в анкету для пользователя: приложение показывает уместную часть внутри разговора.

## Служебная часть

- Ключ раздела, существующий/новый skill_id, версия текста, модуль.
- Источник и точное место в согласованном издании; автор адаптации; статус профессиональной проверки.
- Цель, правила рекомендации, условия остановки; связь с существующим safety.
- Предпосылки, следующий вариант, правила повторения; без решения о замене исключительно со стороны LLM.

## Что видит человек

1. **Название действием.** Например «Сделать паузу перед ответом».
2. **Зачем.** Одно предложение без гарантии облегчения.
3. **Показать пример.** Конкретные обстоятельства, слова и наблюдаемое действие; не выдавать пример за личную договорённость.
4. **Уточнить свою ситуацию.** Один вопрос при недостатке данных; «Не хочу уточнять» прекращает дополнительные вопросы.
5. **Попробовать.** Законченные последовательные шаги с понятным моментом завершения.
6. **Сделать проще.** Уменьшить объём, явно не называть сокращение полным освоением навыка.
7. **Спросить / остановиться / не подходит.** Эти действия доступны без завершения таймера.
8. **Результат.** Сначала выполнение, затем при согласии польза и дальнейшее действие; вопросы не склеивать.
9. **Следующее применение.** Согласовать повторение или вернуться к разбору, напоминания только по желанию.

## Минимум сохраняемых данных

Версия упражнения; собственная ситуация и согласованное действие; offered/accepted/attempted; DONE/PARTIAL/NOT_DONE/REJECTED; выполненная часть; польза (в том числе «стало хуже»); продолжение дела; причина отказа; фактор успеха либо место остановки; согласованный open loop. Пропущенный ответ хранится неизвестным, а не нулём/успехом.

Сначала сопоставить с текущими структурами памяти/исходов; миграцию добавлять только для отсутствующих данных. Показанный пример не становится фактом о человеке. Открытие карточки не означает attempted, таймер не означает completed.

## Редакционная проверка

Есть ли конкретное действие вместо «открыть дело»? Понятно ли, к какому вопросу относятся кнопки? Есть ли свободный ответ? Не предполагается ли пол по имени? Сохраняется ли выбранное ты/вы? Не обещано ли облегчение? Есть ли возможность уточнить? Не повторяется ли неудачная практика автоматически? Что происходит после закрытия приложения?
