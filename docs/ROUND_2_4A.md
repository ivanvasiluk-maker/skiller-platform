# Round 2.4a — evidence-based return on Days 4–6

Дата: 2026-09-14  
Issue: #21

## Пользовательский эффект

На Days 4–6 главный экран объясняет следующий обоснованный ход по последнему сохранённому outcome: повторить полезное, уменьшить неудачный шаг, заменить низко оценённый навык или начать новую проверку при нейтральных данных.

## Правила

- `done/more + helpfulness >= 6` → направление `repeat_helpful`;
- `failed + helpfulness > 3` → `resize_after_failed`;
- `helpfulness <= 3` → `replace_low_fit`;
- нейтральный результат → `first_try`, без автоматического повтора;
- незакрытый текущий plan остаётся в open-loop;
- активный safety flag скрывает карточку практики;
- карточка просит новый конкретный эпизод: safety и совместимость проверяются до следующей рекомендации.

Решение строится общей production-функцией `decideNextStep`; параллельной политики для UI нет.

## Проверка

Тесты покрывают repeat, resize, replacement, нейтральный результат, незакрытый plan, safety block и границу Day 7.

## Не входит в раунд

- transfer между контекстами;
- недельный recap;
- миграции;
- деплой.
