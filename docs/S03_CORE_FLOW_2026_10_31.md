# S03 — основной цикл практики, 31 октября 2026

Статус: технический кандидат; production не обновлён. Основание: S02, PR44.

## Проверенный путь

Существующие D1-сценарии проверяют вопрос → рабочую гипотезу → исправление и подтверждение → личный шаг → start → новый sessionId → восстановление того же действия → фактическое выполнение → отдельную оценку пользы. Также проверяются подробная цепочка, частичное выполнение, пауза/возврат, отказ от навыка и отсутствие выдуманного результата. Эти механизмы повторно использованы.

## Найденный и исправленный разрыв

При отметке «стало хуже» старое NOT NULL хранилище содержит служебный helpfulness=0. Карточки возврата могли выдавать его за числовую оценку пользователя. Старая рекомендация repeat/transfer/resize могла конфликтовать с более поздней отметкой ухудшения.

Теперь дневной возврат, следующий эксперимент и возврат после перерыва называют ухудшение словами; lastOutcome возвращает неизвестную числовую пользу (null). Реальный результат выполнения сохраняется. Ухудшение имеет приоритет над старой рекомендацией: вместо автоматического повтора предлагается разбор и безопасная альтернатива. Проверка безопасности после перерыва сохраняет приоритет. Настоящая оценка 0 без отметки ухудшения остаётся оценкой 0.

Миграции и изменение сохранённых данных не нужны. Ответ API сохраняет форму; меняется интерпретация служебного нуля в continuity. UI использует существующие карточки и переход в разговор.

## Проверки

Добавлены четыре теста continuity: все четыре результата выполнения при ухудшении; конфликт с тремя старыми рекомендациями; возврат после перерыва и приоритет safety; настоящий числовой ноль. D1-сценарий separate-outcome-cycle дополнен проверками сохранённого partial, отсутствия фиктивной оценки и предложения разбора ухудшения.

Результат полного verify фиксируется в PR после завершения прогона. Живая модель, реальный телефон и production в этот спринт не проверялись.

## Оставшиеся барьеры

Не закрыты внешние условия этапа 0 из S02: настоящий production backup/restore в изолированной среде, deployed D1/ingress и внешние автоматические deploy hooks. Это не разрешение запускать ДБТ или публиковать кандидат. Новый визуальный набор тренеров и переименование Скиннера относятся к S04; задачи, импорт и напоминания — к S05–S06.
